# Movie Site

Simple static site for displaying movie data.

How to open
- Open `Move.html` in your browser (double-click or serve with a static server).

Files
- `Move.html` — the main HTML page.
- `Move.css` — styles for the page.
- `Move.js` — JavaScript for dynamic behavior.
- `data.json` — sample data used by the site.

Recommended next steps
- Organize files into folders: `css/`, `js/`, `data/`.
- Rename files for clarity (e.g., `Move.html` → `index.html`) if you plan to host.
- Update `Move.html` asset paths if you move files.

Notes
- This README is intentionally minimal. See `PROJECT_STRUCTURE.md` for a suggested layout and commands to reorganize.
